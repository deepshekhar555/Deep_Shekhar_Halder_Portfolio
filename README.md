# Deep Shekhar Halder Portfolio

Professional portfolio for Deep Shekhar Halder, a B.Tech CSE student working across applied AI, computer vision, robotics, embedded systems and backend engineering.

## Run locally

```powershell
npm install
npm run dev
```

The local development server is available at `http://localhost:5173`.

## Production build

```powershell
npm run build
npm run preview
```

## Included

- Responsive React and CSS interface
- Interactive Three.js profile scene
- Project search and category filters
- Project detail modals
- Experience timeline filters
- Certificate and CV downloads
- Live GitHub profile statistics
- Dark and light themes
- FAQ and validated contact form
- Structured Person metadata, manifest, robots and sitemap
